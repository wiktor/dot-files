# Agent Instructions

This directory contains agent configurations, personal preferences, and workspace skills.

## Structure and Responsibilities

- `AGENTS.md`: Main entry point for agent instructions in this directory.
- `GEMINI.md`: Configuration and usage guidelines for the personal knowledge vault (Second Brain).
- `preferences.md`: Engineering workflow rules, writing styles, and persona guidelines.
- `skills/`: Workspace-specific agent skills. See `skills/README.md` for skill conventions.
